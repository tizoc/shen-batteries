= Types

These opt-in modules extend Shen's System S typechecker. The foundational
theories add reusable union, S-expression, and discarded-result types.
The refinement theories teach the checker how verified runtime predicates and
control-flow conditions constrain otherwise unknown values.

The theories change typechecking only unless their reference explicitly
documents a value-level API such as `(void)`. They do not insert conversions or
runtime casts. Batteries' type-conformance tests exercise both successful uses
and definitions that current Shen must reject without the corresponding theory.
